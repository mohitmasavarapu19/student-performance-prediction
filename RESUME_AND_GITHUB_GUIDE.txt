Student Performance Prediction using LSTM & ANN
Tech Stack: Python | TensorFlow | Keras | Scikit-learn | NumPy | Pandas | Matplotlib

• Designed and implemented two deep learning models (LSTM and ANN) to classify
  student performance into 5 categories (Fail, Pass, Average, Above Average, Good)
  using 7 academic and behavioral features.

• Achieved 86% accuracy with LSTM vs 82% with ANN; conducted full evaluation using
  classification reports, confusion matrices, and accuracy/loss curves.

• Engineered a synthetic dataset of 500 records with feature scaling (MinMaxScaler),
  label encoding, and LSTM-compatible input reshaping (samples, timesteps, features).

• Produced 6 visualization outputs including training history graphs, heatmap confusion
  matrices, and model comparison bar charts using Matplotlib and Seaborn.


── DETAILED VERSION (for project-heavy resume or portfolio) ─

Student Performance Prediction | Deep Learning Project        [Year]
Python · TensorFlow · Keras · Scikit-learn · Pandas · Matplotlib · Seaborn

• Developed an end-to-end deep learning pipeline to predict student academic
  performance, comparing Long Short-Term Memory (LSTM) networks against
  Artificial Neural Networks (ANN) on a 500-sample synthetic dataset.

• Preprocessed data using MinMaxScaler for feature normalization and LabelEncoder
  with one-hot encoding for multi-class output; split data 80/20 for training/testing
  and reshaped input to (samples, timesteps=7, features=1) for LSTM compatibility.

• Built LSTM architecture: LSTM(64) → Dropout(0.2) → Dense(32, ReLU) → Dense(5,
  Softmax); and ANN: Dense(64) → Dropout(0.2) → Dense(32) → Dense(5, Softmax);
  both compiled with Adam optimizer and categorical crossentropy loss.

• LSTM outperformed ANN with 86% vs 82% accuracy (weighted F1: 0.85 vs 0.81),
  demonstrating superior pattern capture in complex educational datasets.

• Generated comprehensive visualizations: training/validation accuracy & loss curves,
  seaborn confusion matrix heatmaps, and a model comparison bar chart.
